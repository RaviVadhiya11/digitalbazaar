# DigitalBazaar — Digital Products Marketplace

Responsive frontend starter for a future multi-vendor digital marketplace.

## Included
- Mobile-friendly homepage
- Demo product cards and sample listings
- Search and category filters
- Popular / New filters
- Seller application and login preview dialogs
- SEO title and description

## Current status: frontend prototype
This is a static frontend only. It does **not** yet provide real seller accounts, authentication, product uploads/storage, order processing, payment checkout, protected downloads, commission accounting, or seller payouts. Do not accept real orders or collect sensitive information until these services are securely implemented and tested.

## Enable GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, select Deploy from a branch.
3. Choose branch `main` and folder `/(root)`.
4. Save and wait for GitHub Pages deployment.
5. Use the exact live URL shown in Pages settings.

## Next phases
1. Authentication and seller/buyer roles.
2. Database for sellers, products, orders and moderation.
3. Secure file storage with private download links.
4. Payment gateway and compliant seller payouts.
5. Admin review, refunds, terms, privacy and tax workflows.

A custom domain must be registered separately and DNS configured after deployment.
